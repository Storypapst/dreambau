An AI agent has two parts: the harness that calls tools, reads files and checks results, and the skills that say how a task is done well. The idea behind "thin harness, fat skills" is to keep the harness as thin as possible and to put the know-how into small, readable skill files.

That is how we work on dreambau.com. One brief describes how a new start page animation is made, with questions first, an acceptance run and a credit line. A new model gets the same brief and delivers inside the same frame. So we compare results instead of rebuilding tools.

It is worth reading because it moves the question: not which model is best, but how good the instructions are that you give it.
