So wird gebaut

Jede Oberfläche entsteht zuerst in Storybook: über 3.800 Stories (2.359 in der Beratungsoberfläche, 1.447 in der Verwaltung), eine automatische Barrierefreiheitsprüfung bei jeder Änderung und Vorher-Nachher-Bilder zu 78 dokumentierten UI-Änderungen. Jedes Repository führt einen Wissensgraphen (Understand-Anything) mit Architektur, Einstieg und offenen Befunden. Technik: React und TypeScript, Spring Boot, Keycloak, Matrix, Kubernetes per Helm-Chart. Quelloffen unter AGPL-3.0.
